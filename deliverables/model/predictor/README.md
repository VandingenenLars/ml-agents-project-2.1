# ML Predictors Pipeline Documentation

## Overview
This part of the projects is responsible for providing
a complete machine learning pipeline for predicting
performance characteristics of Unity ML-Agents training runs and
determining which algorithm (PPO) or SAC) is more efficient
for a given configuration.  

The system consists of:
- **Feature Extractor** (`feature_extractor.py`) -> Produces the train/test  datasets
- **XGBoost Predictor** (`xgboost_predictor.py`) -> Trains regression and classification models.
- **Efficiency Metrics** -> Used to determine whether PPO or SAC is more efficient.
- **Unit Tests** -> Verifies essential pipeline functionalities.

## Inputs
The predictor takes as input the following files generated by `feature_extractor.py`:
- `X_train.csv`
- `X_test.csv`
- `y_train.csv`
- `y_test.csv`

**Feature Columns (X)**:
  - Contains non-target ML-Agent and Hardware configuration fields
  - Categorical fields (`game_type`, `algorithm`, etc.) are one-hot encoded.
  - Numeric fields (`num_units`, `buffer_size`, etc.) are standardized.

**Target Columns (y)**:
The final prediction targets that answer our research questions:
  - `training_time_to_target_sec`
  - `iterations_to_target`
  - `avg_ram_usage_mb`
  - `peak_ram_usage_mb`
