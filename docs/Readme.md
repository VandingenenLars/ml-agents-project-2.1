# Group 10 Project 2.1 - AI Machine Learning

## Overview
This project focuses on the collection and processing of data generated by AI agents trained using the Unity ML-Agents Toolkit, creating a structured dataset suitable for machine learning. The processed data serves as input to a predictive model which is designed to answer specific research questions.

This repository provides all components necessary for a reproducible workflow, including scripts for data collection, preprocessing, feature extraction, training, and evaluation. Included are also the predictive models and necessary scripts that evaluate and visualize the results.  
This forms a complete pipeline from raw agent training to a trained supervised machine learning model with proper evaluation and result visualization.

## Virtual Environment Setup and Installation

This project uses **Conda** for environment management. To set it up:

1. **Install Conda** (if not already installed):   
   - [Miniconda](https://docs.conda.io/en/latest/miniconda.html) or [Anaconda](https://www.anaconda.com/).  
_(Miniconda is lighter and sufficient for our tasks, therefore preferred)_  
2. **Create the environment** from the provided **environment.yml** file:
```bash
conda env create -f deliverables/environment.yml
```
3. **Activating** the environment:
```bash
conda activate mlagents
```
4. **Verify installation**:
```bash
conda list
```
_If `mlagents' environment is present,  setup was successful._

## Role of `training_orchestrator.py`

`training_orchestrator.py` coordinates the full training workflow:

1. Generates a valid ML-Agents YAML configuration  
2. Launches the Unity environment  
3. Starts ML-Agents training  
4. Continuously collects:
   - Training metrics (rewards, steps, success)
   - System metrics (RAM usage, runtime, peak memory)
5. Stores all outputs in a structured run directory  

Each execution produces a **self-contained experiment run**.

## How to run a Training Experiment

1. **Activate** the environment
```bash
conda activate mlagents
```

2. **Run** `training_orchestrator.py`
> While in root directory:
```bash
python -m deliverables.training.training_orchestrator --unity-app path/to/executable --nographics --behavior-name 3DBall
```

### Optional Arguments

| Argument | Default | Description |
|--------|--------|-------------|
| `--no-graphics` | `False` | Run Unity in headless (no-render) mode |
| `--target-reward` | `1.0` | Reward threshold that defines training success |
| `--behavior_name` | `"3DBall"` | ML-Agents behavior name (must match Unity) |
